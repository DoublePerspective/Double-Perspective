# Kindred Compass Games

Static studio website featuring Umbral Purge. Free GitHub Pages hosting; no build process.

## Publishing

In GitHub repository Settings → Pages, select Deploy from a branch → main → /(root) → Save.

Site: https://kindredcompassgames.github.io/kindred-compass-games/
