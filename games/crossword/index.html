One clue at a time

Choose an Across or Down clue. Tap a square, then type with the on-screen keyboard or a physical keyboard. The number in a square matches the clue number. The number in brackets is the answer's length.

Across answers run left to right; Down answers run top to bottom. Shared squares use the same letter in both answers. Tap a crossing square again, or use Across / Down, to change direction.

Check word gently marks incorrect letters in the selected answer. Reveal letter supplies one answer letter; Undo can reverse a reveal or a typed letter. Hints never cost money. There is no timer.

These are themed, free-form crosswords with connected answers and black squares. They use a hand-written English clue bank; new layouts may reuse clues.
